# Reglas de Git

1. **Permiso obligatorio para Git Commit y Git Push:**
   - NUNCA ejecutes `git commit` ni `git push` de forma autónoma o automática.
   - SIEMPRE muestra primero un resumen claro de los archivos modificados y el mensaje de commit sugerido.
   - Pide permiso explícito al usuario antes de proceder con el commit o el push.
